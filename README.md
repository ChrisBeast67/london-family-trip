# London Family Adventure

A standalone family trip planner for London, 28 December 2026 – 2 January 2027.

## Website

The site is a static HTML page in `index.html`. It includes the trip timeline, the 29 December landmarks walk, attraction links, booking-status labels, and a locally saved checklist/notes area.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Choose **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. The public URL will appear on the Pages settings screen.
